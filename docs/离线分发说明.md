# 离线分发包构建说明（维护者用）

面向客户发放的是 `CE转换引擎-v1.0.1-win64-offline.zip`，内置 Python 运行时与全部依赖，客户电脑无需安装 Python、无需联网。

## 分发包结构

```
CE转换引擎-v1.0.1-win64-offline/
├─ app/                     # 程序与 GUI
│  ├─ pdfconv.py
│  ├─ pdfconv-launcher.ps1
│  ├─ VERSION / README.md / ce.ico / background.jpg
├─ python/                  # Python 3.12.10 嵌入式运行时 + Lib/site-packages 全部依赖
├─ docs/screenshot.png      # README 截图
├─ 启动 CE转换引擎.cmd      # 绿色版启动
├─ 安装到本机.ps1           # 安装到 %LOCALAPPDATA%\CEConversionEngine 并创建桌面快捷方式
├─ 使用说明.md / 使用说明.txt
├─ 版权与作者声明.txt
├─ LICENSE / NOTICE.md / CHANGELOG.md / README.md / VERSION
```

## 重新构建步骤（Windows）

1. 下载 Python **3.12.10 embeddable amd64**：
   `https://www.python.org/ftp/python/3.12.10/python-3.12.10-embed-amd64.zip`
2. 解压到 `python/`。
3. 从开发机 venv 复制 `Lib/site-packages` 到 `python/Lib/site-packages`（排除 `pip`、`__pycache__`、`*.pyc`）。
4. 修改 `python/python312._pth`：
   ```
   python312.zip
   .
   Lib\site-packages
   import site
   ```
5. 复制 `pdfconv.py`、`pdfconv-launcher.ps1`、`VERSION`、`README.md`、`ce.ico`、`background.jpg` 到 `app/`。
6. 复制根目录文档、`desktop/install-offline.ps1`（改名为 `安装到本机.ps1`，UTF-8 BOM）、`desktop/启动 CE转换引擎.cmd`、`docs/使用说明.md`、`docs/版权与作者声明.txt`。
7. 验证（不联网）：
   ```powershell
   .\python\python.exe .\app\pdfconv.py doctor
   .\python\python.exe .\app\pdfconv.py pdf2txt 测试.pdf -o .\output
   powershell -ExecutionPolicy Bypass -File .\app\pdfconv-launcher.ps1 -SelfTest 测试.pdf
   ```
8. 压缩整个文件夹为 ZIP，附 SHA256；上传 GitHub Release。

## 注意

- 分发包内含 `.wps` 桥接所需的 pywin32；客户仍需自行安装 WPS Office 才能转换 `.wps`。
- 客户电脑要求 Windows 10/11；PowerShell 5.1 系统自带。
- 分发包约 160MB（ZIP）/ 400MB（解压后）。
