# CE转换引擎（Conversion Engine）v1.0.1 使用说明

**作者：温酒会知音**  
**版权所有 © 2026 温酒会知音**

## 一、软件简介

CE转换引擎是一款运行在 Windows 10/11 上的**本地离线**文档转换工具，支持：

- PDF → Word / Excel / PPT / 图片 / TXT / 纯图 PDF / 可搜索 PDF
- PDF 合并、拆分、提取页面、提取图片
- 本地 OCR（扫描件文字识别，离线）
- 图片 → PDF
- PDF ↔ OFD（OFD 转 PDF/Word/Excel/PPT/图片/TXT）
- WPS(.wps) ↔ Word / PDF / TXT / OFD

所有转换均在本机完成，**不上传文件、不需要联网**。`.wps` 格式需要客户电脑已安装 WPS Office（调用本机 WPS，不联网）。

## 二、绿色版（免安装，最简单）

1. 将压缩包**完整解压**到任意文件夹（例如 `D:\CE转换引擎`）。
   > 注意：必须保留解压后的 `python` 和 `app` 两个文件夹，不能只拷贝快捷方式。
2. 双击 `启动 CE转换引擎.cmd`，即可打开图形界面。
3. 如需命令行：`python\python.exe app\pdfconv.py doctor` 或 `python\python.exe app\pdfconv.py --help`。

## 三、安装到本机（推荐，桌面有快捷方式）

1. 右键 `安装到本机.ps1` → “使用 PowerShell 运行”；
   或在 PowerShell 中执行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\安装到本机.ps1
   ```
2. 安装位置：`%LOCALAPPDATA%\CEConversionEngine`（当前用户目录，无需管理员权限）
3. 安装完成后，桌面会出现 **“CE转换引擎（Conversion Engine）”** 快捷方式，双击即可使用。

卸载：关闭软件后，删除 `%LOCALAPPDATA%\CEConversionEngine` 文件夹和桌面快捷方式即可。

## 四、界面使用

1. 点 **“添加文档...”** 选择要转换的文件，可多选；也可以直接把文件**拖进文件列表**。
   - 支持：PDF、OFD、WPS、Word(doc/docx)、RTF、TXT
2. 在 **“转换方式”** 下拉框选择转换动作（共 28 种）。
3. 在 **“输出目录”** 选择保存位置；点 **“设为默认”** 可记住该目录。
4. 需要指定页码时，在 **“页码/范围”** 填写，例如 `1-3`、`1,4,7`；留空表示全部。
5. 点 **“开始转换”**，状态栏显示进度，日志区实时显示每步结果：
   - 绿色 = 成功，红色 = 失败，橙色 = 警告
   - 双击日志区可打开本次完整日志文件；右键可复制日志/查看关于与版权
6. 转换完成后会播放提示音（可在界面关闭“提示音”）。
7. “取消”可中止正在进行的任务。

## 五、WPS(.wps) 格式说明

- 需要客户电脑安装 **WPS Office**（本软件通过本机 WPS 的 COM 接口读写 .wps，不联网、不调用云端/VIP 转换引擎）。
- 支持：`.wps` → Word/PDF/TXT/OFD；Word/RTF/TXT/PDF/OFD → `.wps`。
- 如果没有安装 WPS Office，执行 .wps 相关动作会提示“未检测到 WPS Office”。

## 六、输出与日志

- 默认输出目录：桌面 `pdfconv-output`；可在软件中修改并“设为默认”。
- 日志：`%LOCALAPPDATA%\CEConversionEngine\app\..\logs\run-*.log`
  （绿色版为解压目录下的 `logs` 文件夹）
- 同一文件多次转换，输出文件已存在时会提示；勾选/执行时确认覆盖即可。

## 七、常见问题

- **双击没反应**：Windows 可能拦截了未签名脚本；右键 `启动 CE转换引擎.cmd` → 属性 → 解除锁定，或右键 `安装到本机.ps1` 选择“使用 PowerShell 运行”。
- **杀毒软件提示**：本软件完全离线、不联网；如被拦截请添加信任（可查看源码：https://github.com/ThePandaQ/ce-conversion-engine）。
- **提示找不到 Python**：请确认解压完整，`python\python.exe` 是否存在；绿色版不要单独移动 `app` 文件夹。
- **图标/快捷方式没变化**：按 F5 刷新桌面或重新运行 `安装到本机.ps1`。
- **转换失败**：查看日志区红色行，或双击打开完整日志；也可以把日志发给作者。
